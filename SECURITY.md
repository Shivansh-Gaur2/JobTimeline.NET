# Security Policy

## Supported versions

JobTimeline.NET is pre-release and has no published or supported package versions yet.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue. Contact the repository owner privately through their GitHub profile with a concise description, affected revision, reproduction steps, and potential impact. Allow reasonable time for acknowledgement and remediation before public disclosure.

Avoid including secrets, production payloads, access tokens, or other sensitive customer data in a report.
