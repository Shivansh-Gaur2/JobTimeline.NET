# Contributing to JobTimeline.NET

Thank you for considering a contribution.

## Before you begin

Open an issue or start a discussion before substantial changes so the proposed scope and public API direction can be agreed on. Keep pull requests focused; avoid unrelated formatting or refactoring.

## Development workflow

1. Use the .NET 8 SDK.
2. Run `dotnet build JobTimeline.sln`.
3. Run `dotnet test JobTimeline.sln`.
4. Add or update focused tests when changing implemented behavior.

Follow the repository's `.editorconfig`. Do not commit build output, credentials, production payloads, or other sensitive data.

## Pull requests

Describe the problem, the chosen approach, and validation performed. By contributing, you agree that your contribution may be distributed under the repository's MIT License.
